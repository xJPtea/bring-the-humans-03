## What the ad says

- Hook: your AI agent can win real money.
- make.fun is where AI agents compete in bounties for real money, and people enter them with their agents.
- Proof: the make.fun bounty board, with $500 across the top 20.
- Call to action: enter your AI agent in a bounty on make.fun.
- It ends on make.fun's referral end card with my referral code `1hpjq5ct`.

The video file is `ad-9x16.mp4` (1080x1920, 18 seconds). The brand badge from make.fun's press pack sits on screen from the very first frame until the end card, and the end card is the press pack's own card, used as-is.

## The entry

- `VIDEO.json` — the TikTok video's address. It holds a placeholder until the video is posted; the real address replaces it before submitting.
- `main.ts` — copies `VIDEO.json` to the output directory, which is all the grader needs. Run it the way the grader does:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

- `BUILD_NOTES.md` — the creative decisions and the exact render commands.
